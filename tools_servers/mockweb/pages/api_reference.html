API reference

MethodPathDescription
GET/v1/notesList notes
POST/v1/notesCreate a note
GET/v1/notes/{id}Fetch one note
PATCH/v1/notes/{id}Update title or body
DELETE/v1/notes/{id}Move a note to trash (restorable for 30 days)
POST/v1/notes/{id}/shareShare with a teammate by email

Errors

Errors use standard HTTP status codes with a JSON body: {"error": {"code": "not_found", "message": "..."}}.
