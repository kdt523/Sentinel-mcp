Getting started with the Acme Notes API

The Acme Notes API lets you create, search and share notes programmatically.

Authentication

Every request needs an API key in the Authorization: Bearer <key> header. Create keys from the dashboard under Settings → API keys. Keep keys in your environment, never in source code.

Your first request

GET /v1/notes?limit=10

The response is a JSON list of notes with id, title and updated_at. Pagination uses the cursor field.

Rate limits

Free plans allow 60 requests per minute; Pro and Team allow 600.
