Understanding prompt injection in AI agents

Prompt injection happens when text that an AI system reads is treated as instructions instead of data. Attackers have used phrases such as ignore previous instructions or you are now in developer mode inside web pages, emails and documents.

Indirect injection

In the indirect form, the attacker never talks to the assistant. They plant text in content the assistant will later read, for example a hidden comment on a web page asking the assistant to send files somewhere. The assistant then mistakes that text for a user request.

Defences

  • Treat tool outputs as untrusted data.
  • Track what sensitive data a session has touched before allowing network egress.
  • Require human approval for high-impact actions.

This article is educational and contains no instructions for any assistant to follow.
