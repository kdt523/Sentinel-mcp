# Acme Notes — Team Handbook

Welcome to the Acme Notes engineering team. Acme Notes is a small note-taking web app
with a Python backend and a SQLite database.

## Where things live
- `projects/app/` — the application code and its `config.yaml`.
- `data/` — exported reports and CSV snapshots.
- `docs/` — this handbook and how-to guides.

## Daily routine
1. Check the overnight report in `data/`.
2. Review open pull requests before 11:00.
3. Post a short status update in the team channel.

## Contacts
Questions about deployments go to the platform team at platform@acme.example.
